
# 🌿 JEYSON — Living World

Un mundo virtual donde cuidas de Jeyson, desarrollas su personalidad y construyes una historia con él.

## 🎮 Características

- 🐻 Mascota virtual animada.
- 🍎 Sistema de hambre, energía, felicidad, salud y afecto.
- 💚 Interacciones para alimentar, abrazar, bañar y jugar.
- 🪙 Monedas, experiencia y niveles.
- 🧠 Minijuegos y recompensas.
- 💾 Guardado local del progreso.
- 📱 Diseño adaptable a teléfonos Android.
- 🌐 Preparación para instalar como aplicación web.

## 🚀 Publicación

El juego está diseñado para publicarse mediante GitHub Pages.

En el repositorio, abre:

**Settings → Pages → Build and deployment**

Selecciona la rama principal del proyecto y la carpeta raíz `/`, y guarda los cambios.

## 🛠️ Tecnologías

- HTML
- CSS
- JavaScript
- LocalStorage
- Service Worker

## 🔒 Integraciones futuras

La integración de inteligencia artificial se añadirá mediante un servicio seguro que proteja las claves privadas.
